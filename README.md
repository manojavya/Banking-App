# Banking-App
A simple banking app made in C++ can be customised by the user by modifying source code!

## Please Follow these instructions
This application needs the `functions.txt` file to function properly this programs menu is written in that file without it you will be hitting errors! Also there is a `errorcodes.txt` with all the error codes and their meanings so you may download the error codes optionally.
